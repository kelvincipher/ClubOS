# Five-minute ClubOS demonstration

Use two browsers: president and student. Use a third phone for QR scanning if available. Before presenting, open your Render `/api/health` URL so the free backend is awake.

1. **One workspace, one story.** Sign in as president. Show the club directory and club-specific workspace.
2. **Recruit.** Create a campaign. In the student browser, register a new account, select the club and apply. Refresh on the president side, move to Interview, then Accept. Refresh on the student side to show their member profile. This is the same applicant becoming a member, with no second entry in a spreadsheet.
3. **Connect.** Create an event. The student registers and opens the personal QR ticket. Scan with an officer's phone or copy the link to Events → Check in. Confirm attendance. Repeat once to show duplicate prevention. Export attendance CSV.
4. **Keep the knowledge.** Add a shared handbook link and a task. Mark the task complete.
5. **Pass it on.** Open Handover, choose the student, add notes, check confirmation and transfer. Refresh both browsers: the new person is president, the old president is an officer. Member, event, attendance and knowledge records remain.

If the sample event has passed, create a new one. Dates are shown in each user's local timezone. Never show service account keys or environment settings during a public demo.
